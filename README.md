# Balance — демонстрационный редизайн

**[Открыть макет сайта](https://efimbyrlov4-pixel.github.io/balance-fitness-demo/)**

Адаптивный макет с интерактивными плитками, выбором трёх клубов, каталогом материалов и фотогалереей.
Материалы 66 страниц и 500 оригинальных изображений с balance-fit.ru сохранены в docs.
Фото и материалы принадлежат Balance. Это неофициальная демонстрация дизайна.
Запись, личный кабинет и актуальное расписание открываются на официальном сайте.

## Структура
- docs/index.html — главная страница
- docs/style.css — оформление и мобильная версия
- docs/app.js — интерактивные разделы
- docs/data — исходные материалы и каталог изображений
- docs/assets — оригинальные фотографии и графика

GitHub Pages публикует каталог docs ветки main. Сайт работает самостоятельно, без зависимости от предыдущего хостинга.
